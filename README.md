## 排除選項

一般與模擬練習均可按各選項右側「排除」，劃掉並暫時停用該選項；按「恢復」或「清除排除」即可撤回。排除已選答案會取消該選擇，但不會自動選其他答案。多選題可逐項操作；仍需選答案、標記把握並確認提交。提交後清除劃線以正常顯示給分與詳解；下一題重新開始。排除僅是當題輔助，不寫入作答紀錄，重新整理不保留。

瀏覽器回歸：在已安裝 Playwright 與 Chromium 的環境啟動 `npm start` 後，執行 `node scripts/check_option_elimination.cjs`；可附測試網址，或用 `CHROMIUM_PATH` 指定瀏覽器。涵蓋排除／恢復、全排除、清除、鍵盤、單多選給分、模擬練習不揭答及手機版面。

## 把握程度、間隔複習與單題筆記

所有選擇題現在均需選答案、標記「有把握／猜的／不會／不確定」，再確認提交。錯題與不確定題（含猜對）可立即由首頁「錯題與猜對重練」重做；「開始到期複習」則僅抽已到期題，優先最早到期者。答錯或不確定隔24小時複習；連續有把握答對的間隔依次為1、3、7、14天，答錯或不確定後重設。一律給分與任一單選給分題不安排此複習。舊作答紀錄保留，舊版答對不會被誤標為猜對。

作答後展開「記下錯因／單題筆記」可選錯因並留下最多4000字筆記（可貼GPT重點，仍需核對）。筆記自動儲存在目前瀏覽器；「弱點分析」可列出筆記並重練單題，「匯出學習紀錄」同時包含作答及單題筆記。匯出僅供備份查看，尚無還原匯入或雲端同步。模擬練習期間不提前顯示答案、GPT提示與筆記編輯，完成後再回顧。

## 詢問 GPT 詳解

作答後的解析區提供「複製提問並開啟 ChatGPT」及「只複製提問」。提問含當題、選項、官方給分、本人選擇、原卷與附圖連結，不含其他作答紀錄。短提問嘗試帶入 ChatGPT 網址；過長或未帶入時請貼上已複製的文字，確認後自行送出。可能需登入 ChatGPT。複製失敗時可展開已選取的提問手動複製。此功能不使用 API、不自動送出，也不把 GPT 回覆存回題庫；附圖或來源無法讀取時需自行上傳，回覆仍須核對。
