# 築考練習室

公開網址：https://s100009986075993-boop.github.io/-/

目前版本：4320道歷屆選擇題已轉錄為可直接作答的文字題幹及選項；僅需要圖表、公式或圖像選項的題目附單題圖，整頁原卷移至預設收合的來源核對區。24題的特殊字元或數學排版另標示需核對，其他文字亦可回原卷查驗，尚未逐題完成專家覆核。原始答案及更正規則的canonical SHA256在轉錄前後一致。

首頁可按「先試做有詳解的題目」，或於題目範圍選「已有詳解草稿」。首批23題提供解題思路、四選項理由及可點擊來源，均標示為編寫草稿，並非官方解析。其他4297題詳解尚待編寫；不得把僅重述答案視為已完成詳解。新增紙色／酒紅／青綠介面，支援手機作答。

更新文字題庫：先執行所需的原始匯入，再執行 `python3 scripts/native_questions.py` 及 `python3 scripts/enrich_native_questions.py`。後者保存有原卷依據的人工轉錄修正與 `data/curated-explanations.json` 詳解；不可只跑舊匯入而發布佔位題。新詳解需核對答案、公式與適用法規，維護 draft/reviewed/pending 狀態。之後執行 `npm test`、瀏覽器回歸、推送main並執行 `python3 scripts/publish_pages.py`。

下列較早的資料匯入紀錄保留供維護參考，功能狀態以本段為準。

建築師國考練習網站第一版。原生 HTML/CSS/JavaScript，無第三方套件。

## 啟動與驗證

在 `/workspace/-` 執行 `npm start`，HTTP 服務使用 3000 埠。執行 `npm test` 驗證題庫匯入與統計邏輯。

## 目前限制

內建 97 年建築結構 40 題選擇題及三題示範題。原卷另有兩題申論題，僅提供原卷閱讀。第25題依更正表接受 B 或 C。兩份答案上傳檔雜湊相同，均為更正表，無更正前答案可比較。正式題目保留題圖與原卷；解析及現行法規待核對，章節為整理分類。資料及來源雜湊見 data/97-structure-manifest.json。尚未提供 PDF/OCR、AI 生成、法規查證、帳號、跨裝置同步、圖面評閱及正式國考計分。模擬練習重新整理會中止；單題已提交的紀錄仍保存。關閉私人瀏覽或清除網站資料可能遺失紀錄。匯出的紀錄暫不支援重新匯入。

正式題庫請提供原始 PDF、官方答案、更正公告、年度及科目。解析與法規來源需核對後才能發布。網站不含金鑰，不會把資料送往 AI 服務。
